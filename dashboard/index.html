How this board is priced

Every implied value is computed from the snapshot's own figures, by one formula applied to every row. No protocol is priced by name.

implied value = TVL × peer multiple × momentum × track record × breadth

  • Peer multiple. Each live peer's market-cap / TVL ratio is first winsorised to [0.01, 5], so a peer with a near-zero TVL cannot price a category. The category's median ratio is then weighted n / (n + 4) against the all-market median (… across … live protocols here), so a category needs a deep peer set before its own median prices the board, and every multiple is clamped between 0.02 and 3. Each protocol's page shows its peer count and its category's raw median, so a thin peer set is never hidden.
  • Momentum. 1 + 0.35 × the 7-day TVL change, clamped between −50% and +100%. An unreported change is neutral and flagged, never invented.
  • Track record. 0.78 + 0.34 × age / (age + 365 days), from the day DefiLlama began tracking the protocol: the longer it has run with no token, the more of its record a buyer can see. An unreported listing date scores as 150 days and is flagged.
  • Breadth. 1 + 0.015 per extra chain, up to twelve: a token distributed across more chains reaches more holders.

The factors are rounded before they are multiplied, so the breakdown on each protocol's page reproduces its board value to the dollar. The launch score (0–100) is a separate readiness gauge blending size, track record, momentum and breadth; it sorts the page but never moves a rank.

Who gets ranked

The board covers every protocol on the snapshot's watchlist, then applies the watchlist's own product test at every size: a candidate must record no token, and must not be an exchange, a bridge-balance entry (DefiLlama's bridge rows are mostly balances of assets that already trade), a versioned pool of another protocol, or a wrapped, staked or staking product of one. Rows in staking-like categories that survive the test carry a product-risk flag instead of being silently dropped. A protocol is said to record no token, never to have none: the snapshot is DefiLlama's record, and a record is not proof.

Reading the flags

Flags are warnings from the protocol's own record: a shrinking TVL, a parabolic week, a short track record, a single chain, a small base, or a figure the snapshot does not report. A flagged row keeps its rank; the flag is there so a farmer can price the risk the model cannot.

An implied value is this radar's own claim about what a token would be worth if the protocol's record stayed as it is. It is not a prediction that a token will be issued, and it is not make.fun's claim. Farm plans are checklists, not financial advice; costs are estimates in US dollars.
